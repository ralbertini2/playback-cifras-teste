# Playback Cifras V12

Versão com nova identidade visual e controles maiores para tablet/iPad.

## Principais mudanças
- Logo pequeno no topo esquerdo.
- Interface escura com identidade amarelo/verde.
- Controles grandes e flat na parte inferior.
- Linha de progresso personalizada.
- Botões: Voltar, Tocar/Pausar, -10s, +10s, Repetir, Próxima e Playlist.
- Mantém as melhorias da V11: PDF rápido, MP3 em segundo plano, cache local e pré-carregamento.

## Publicação
Depois de enviar ao GitHub Pages, edite `config.js` e preencha:

```js
GOOGLE_CLIENT_ID: "SEU_CLIENT_ID",
GOOGLE_API_KEY: "SUA_API_KEY",
ROOT_FOLDER_ID: ""
```
