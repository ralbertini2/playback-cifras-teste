# Playback Cifras V11

Versão focada em desempenho:
- PDF abre imediatamente ao trocar música.
- MP3 carrega em segundo plano com cache local.
- Pré-carrega as próximas músicas.
- Biblioteca por estilos busca subpastas em paralelo.
- Service worker evita prender versões antigas do app.

Depois de publicar no GitHub Pages, preencha `config.js` com GOOGLE_CLIENT_ID e GOOGLE_API_KEY.
